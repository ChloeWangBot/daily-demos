        这条垫子怎么判断
        
    
          
  • 出现「决定 / 拍板 / 结论 / 先不做 / 回滚」时，记成决策。
    • 
          
  • 出现「请 / 负责 / 待办 / 下一步 / @某人」时，记成待办。
    • 
          
  • 「张三负责」「负责人：张三」算明确；「@张三」「请张三」「让张三」算推断。对不上就写未指定。
    • 
          
  • 「周五前」「下周一会前」「10月8日」「截止…」会写进下一步。纯状态句，比如设备坏了，会跳过。
    •
